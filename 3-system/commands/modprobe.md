# `modprobe`

```text
Usage: modprobe [-qfwrsv] MODULE [symbol=value]...

	-r	Remove MODULE (stacks) or do autoclean
	-q	Quiet
	-v	Verbose
	-f	Force
	-w	Wait for unload
	-s	Report via syslog instead of stderr
```
