# `rpm`

```text
Usage: rpm -i PACKAGE.rpm; rpm -qp[ildc] PACKAGE.rpm

Manipulate RPM packages

Commands:
	-i	Install package
	-qp	Query package
	-i	Show information
	-l	List contents
	-d	List documents
	-c	List config files
```
