# `dumpleases`

```text
Usage: dumpleases [-r|-a] [-f LEASEFILE]

Display DHCP leases granted by udhcpd

	-f,--file=FILE	Lease file
	-r,--remaining	Show remaining time
	-a,--absolute	Show expiration time
```
