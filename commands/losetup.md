# `losetup`

```text
Usage: losetup [-o OFS] LOOPDEV FILE - associate loop devices
	losetup -d LOOPDEV - disassociate
	losetup [-f] - show

	-o OFS	Start OFS bytes into FILE
	-f	Show first free loop device
```
