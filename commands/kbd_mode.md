# `kbd_mode`

```text
Usage: kbd_mode [-a|k|s|u] [-C TTY]

Report or set the keyboard mode

	-a	Default (ASCII)
	-k	Medium-raw (keyboard)
	-s	Raw (scancode)
	-u	Unicode (utf-8)
	-C TTY	Affect TTY instead of /dev/tty
```
