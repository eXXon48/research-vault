# `lzop`

```text
Usage: lzop [-cfvd123456789CF] [FILE]...

	-1..9	Compression level
	-d	Decompress
	-c	Write to stdout
	-f	Force
	-v	Verbose
	-F	Don't store or verify checksum
	-C	Also write checksum of compressed block
```
