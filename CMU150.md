## Platform summary
- Firmware 74.00.324 is compatible with the ND Gen1.
- The root filesystem is a read-write transactional filesystem mounted read-only;
  `/config-mfg` (keys / calibration) is a read-only squashfs.
- `cmu` is uid 0. On fw74 the old `jci` default password does not match and password login
  is disabled by default; access is via the dealer key or an added key ([[SSH Access]]).
